## 四、基础设施缺失

| 缺失项 | 影响 | 优先级 |
|--------|------|--------|
| ❌ 无任何 REST Controller | 前端无法对接 API | **P0-必须** |
| ❌ 无用户认证系统（user 表、AuthController、JWT 拦截器） | 无法登录、无权限控制 | **P0-必须** |
| ❌ 无策略引擎 | 照明策略无法自动执行 | **P1-重要** |
| ❌ 未订阅 heartbeat topic | 无法检测设备心跳和在线状态 | **P1-重要** |
| ❌ 未订阅 vision/voice MQTT topic | 视觉/语音事件无法接入 | P2-一般 |
| ❌ 未处理 command/ack 反馈 | 控制指令无执行结果回传 | **P1-重要** |
| ❌ 无前端代码 | 无可视化界面 | P2-一般（需新建前端项目） |

## 六、建议实施路线

### 第一阶段：打通基础链路（P0）

1. **创建 user 表**（id, username, password, role）
2. **AuthController + JWT 拦截器** — 登录鉴权（谭佩）
3. **DeviceController** — 设备列表/详情/搜索（舒羽）
4. **TelemetryController** — 最新遥测/历史趋势（舒羽）

### 第二阶段：业务闭环（P1）

5. **ControlController** — 手动控制指令下发（配合 MQTT 发布）
6. **告警服务** — 离线检测定时任务 + 告警生成
7. **策略引擎** — 解析 lighting_policy 规则 + 自动决策
8. **审计日志** — 关键操作自动写入 audit_log

### 第三阶段：创新功能（P2）

9. **IR-09 智能问答** — AgentController + RAG（霍英杰）
10. **IR-07 健康评分** — 评分计算 + 维护建议
11. **IR-10 节能报表** — 能耗统计查询
12. **IR-05/IR-06** — Vision/Voice 事件处理
13. **IR-08 大屏聚合 API** — 仪表盘数据

### 第四阶段：前端与联调

14. 前端 Vue3 项目搭建
15. 前后端联调
