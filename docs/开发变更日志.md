## 五、安全可信控制（审计日志）

所有关键写操作均记录 `audit_log` 表，覆盖以下 action：

| action | 触发接口 |
|--------|---------|
| LOGIN | POST /api/auth/login |
| CONTROL | POST /api/devices/{deviceId}/control |
| DEVICE_CREATE / UPDATE / DELETE | POST/PUT/DELETE /api/devices/** |
| ALARM_CREATE / UPDATE / DELETE | POST/PUT/DELETE /api/alarms/** |
| ALARM_HANDLE / BATCH_HANDLE / BATCH_DELETE | PUT/DELETE /api/alarms/** |
| POLICY_CREATE / UPDATE / DELETE / TOGGLE | POST/PUT/DELETE /api/policies/** |

每条审计日志包含：`operator` / `action` / `target_type` / `target_id` / `detail` / `result` / `ip_address` / `operated_at`。
