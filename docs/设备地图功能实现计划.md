# 设备地图功能实现计划

## 背景

在数字孪生 Dashboard 页面集成高德地图，通过经纬度展示所有路灯设备的位置分布。地图标记根据设备状态（在线/离线/异常/停用）显示不同颜色，支持点击标记高亮、弹出详情信息窗，支持从外部（如设备列表）触发高亮，支持千级设备的标记聚类。

## 技术选型

**高德地图 JS API 2.0** — 国内访问快、中文文档完善、内置暗色主题、自带标记聚类和信息窗体。

## 实现步骤（共 6 步）

### Step 1: 坐标工具 `src/utils/coordinate.js`

纯算法文件，无依赖，先写先测。

- `parseLocation(str)` — 解析 `"106.5622,29.5621"` → `{ lng, lat }`
- `wgs84ToGcj02(lng, lat)` — 标准火星坐标转换算法
- `autoToGcj02(lng, lat, assumeGcj02)` — 条件转换，默认不转（假设已是 GCJ-02）

### Step 2: AMap 加载器 `src/composables/useAMap.js`

动态加载高德 SDK 脚本，遵循项目 composable 模式（参考 `useChartScale.js`）。

- 从 `import.meta.env.VITE_AMAP_KEY` 读取 Key
- 单例加载，防止重复注入 `<script>` 标签
- 同时加载 `AMap.MarkerCluster` 插件
- 返回 `{ AMap, loaded, loading, error }` 响应式状态
- 15 秒超时 + 错误提示

### Step 3: 地图组件 `src/components/DeviceMap.vue`

核心组件，`<script setup>` 风格。

**Props**: `devices`, `highlightDeviceId`, `height`  
**Emits**: `marker-click`  
**Expose**: `highlightDevice()`, `clearHighlight()`, `fitBounds()`

**功能清单**:

1. **标记渲染** — 解析 `location`，按 status 生成不同颜色的圆形标记（`AMap.Marker` + 自定义 content DOM 元素）
2. **标记聚类** — `AMap.MarkerCluster` 处理千级设备，缩放小时自动聚合显示数字
3. **点击高亮** — 点击标记 → 脉冲动画（CSS `@keyframes`）+ 弹出 `AMap.InfoWindow`（设备名、状态、健康分、"查看详情"链接）
4. **外部高亮** — watch `highlightDeviceId` prop → `map.setCenter()` + 脉冲高亮
5. **暗色底图** — `mapStyle: 'amap://styles/dark'`
6. **标记状态色**:
   - 在线 (status=1): `#4caf82` 绿色
   - 离线 (status=2): `#9e9e9e` 灰色
   - 异常 (status=3): `#ffa726` 橙色
   - 停用 (status=0): `#888` 暗灰
7. **缩放适配** — `ResizeObserver` + ScreenScale 的 `--scale-ratio` CSS 变量
8. **Tab 切换** — watch 容器可见性 → `map.resize()`

### Step 4: Dashboard 集成 `src/views/Dashboard.vue`

改动现有 Dashboard 页面的右侧面板：

- 现有 `.district-card` 改造为 Tab 切换面板（"地图" / "列表"）
- 新增 `allDevices` 状态，在 `onMounted` 中调用 `fetchAllDevicesForMap()`
- 引入 `<DeviceMap>` 组件，传入设备数据和选中 ID
- 点击设备标记 → 跳转到设备详情页 `/devices/${deviceId}`
- 地图和分区列表通过 Tab 切换，默认显示地图

### Step 5: API 补充 `src/api/devices.js`

新增轻量方法：

```js
export function fetchAllDevicesForMap() {
  return fetchDeviceList({ pageSize: 10000 })
}
```

（后续后端可替换为专用 `GET /api/devices/map-locations` 接口，返回精简字段）

### Step 6: 环境配置 `.env`

```
VITE_AMAP_KEY=你的高德Key
```

注册地址：https://lbs.amap.com/ → 控制台 → 应用管理 → 创建应用 → 添加 Key（选择"Web端(JS API)"）

## 验证方式

1. 启动项目 `npm run dev`，打开 Dashboard 页面
2. 确认地图正常加载（高德瓦片 + 暗色主题）
3. 确认设备标记颜色与状态对应（在线绿/离线灰/异常橙）
4. 点击标记 → 脉冲高亮 + 信息窗弹出
5. 点击"查看详情" → 跳转到设备详情页
6. 滚动缩放 → 标记聚类/展开
7. 切换 Tab 到"列表" → 分区设备状态表正常显示
8. 切换回"地图" → 地图正常 resize 无变形
9. 窗口缩放 → 地图自适应
