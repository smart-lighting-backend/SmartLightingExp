# 路灯常见故障手册

本文档用于导入 MaxKB 知识库，作为维护知识库问答的数据源。

## 灯不亮怎么办

1. 查看平台设备状态是否为在线。
2. 查看最近一次心跳时间和遥测上报时间。
3. 检查控制指令记录，确认是否有 OFF 或低亮度调光指令。
4. 检查供电线路、空开、保险丝和灯具电源模块。
5. 如果设备在线但无响应，重新下发 ON 指令并观察 MQTT 指令确认。
6. 如果仍不亮，安排现场检查灯具驱动、电源和灯珠。

## 通信中断如何排查

1. 查看设备最后心跳时间，确认中断持续时间。
2. 检查网关、SIM 卡、路由器或现场网络供电。
3. 检查 MQTT Broker 地址、端口、账号密码和 Topic 前缀是否正确。
4. 在平台查看同一区域其他设备是否同时离线。
5. 如果同区域批量离线，优先排查网络或网关。
6. 如果单灯离线，优先排查设备通信模块、天线和本地供电。

## 亮度无法调整怎么办

1. 确认设备状态为在线且启用。
2. 检查下发指令是否为 DIMMING，亮度值是否在 0 到 100 范围。
3. 查看 control_command 表中的状态和结果详情。
4. 检查设备是否支持调光协议。
5. 如果 MQTT 下发成功但现场亮度不变，检查驱动电源和调光线。

## 设备频繁离线怎么办

1. 查看离线发生时间是否集中在固定时段。
2. 检查现场供电是否波动。
3. 检查通信信号强度和网关负载。
4. 查看设备是否频繁重启。
5. 对同型号设备进行对比，判断是否为硬件批次问题。

## 自动控制不生效怎么办

1. 确认照明策略已启用且未删除。
2. 检查策略 conditions 是否为合法 JSON。
3. 确认遥测数据中 illuminance、pir、traffic_flow 等字段存在。
4. 检查设备 last_manual_at，手动控制后 30 分钟内自动策略会跳过。
5. 查看 decision_log 是否有 NO_MATCH 或 MATCH_EXECUTED 记录。

## 阈值设置后没有立即变化怎么办

1. 阈值修改只更新策略配置，不会主动补发控制指令。
2. 等待设备下一次上报遥测后，策略引擎会重新判断。
3. 如果需要立即改变灯光状态，可手动下发控制指令。
4. 检查阈值单位是否为 lux，范围是否合理。

## MQTT 指令下发失败怎么办

1. 检查后端日志中的 MQTT publish failed 信息。
2. 确认 Broker 地址、端口、账号密码正确。
3. 确认 client-id 没有被其他进程重复占用。
4. 检查 Topic 格式是否为 streetlight/{deviceId}/command。
5. 确认设备订阅了对应 Topic。

## 健康评分过低怎么办

1. 查看 alarm_record 中的告警类型和级别。
2. 检查最近遥测是否存在温度过高、长时间离线或传感器异常。
3. 查看设备历史控制记录，排除频繁开关导致的异常。
4. 安排现场巡检，重点检查供电、通信模块和灯具驱动。
