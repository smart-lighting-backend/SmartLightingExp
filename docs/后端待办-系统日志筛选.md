## 1. 当前状况分析

### 为什么看不到数据？

经过完整链路追溯（`SystemLog.vue → log.js → request.js → Vite proxy → AuditLogController`），发现三个相互叠加的问题：

| 层面 | 原因 | 严重度 |
|------|------|--------|
| **Mock 降级链路断裂** | 后端未启动时登录页自动降级为 Mock 模式（产生 `mock-token-dev-xxx` Token），但 `log.js` 没有像其他页面一样实现 Mock fallback，API 调用失败后静默返回空数组 | 高 |
| **数据库无种子数据** | 所有 SQL seed 文件均未插入 `audit_log` 记录，即使后端启动表也是空的 | 中 |
| **API 无筛选参数** | `GET /api/logs/system` 只接受 `page`、`size`，无法按操作人、操作类型、日期范围查询 | 低（功能增强） |

### 关键发现：Mock 降级的不一致

其他页面（Dashboard、Devices、策略等）都用 `safeCall(apiFn, mockData, endpoint)` 包装，API 失败时自动降级为 Mock 数据：

```javascript
// dashboard.js — 有 Mock fallback
export function fetchDashboardStats() {
  return safeCall(
    () => request.get('/api/dashboard/stats'),
    MOCK_STATS,  // ← 有 Mock
    'GET /api/dashboard/stats'
  )
}

// log.js — 没有 Mock fallback
export async function getSystemLogs(page = 1, size = 50) {
  try {
    const res = await request.get('/api/logs/system', ...)
    // ...
  } catch (e) {
    if (e?.bizCode) throw e
    return { code: 200, data: { list: [], total: 0 } }  // ← 直接返回空
  }
}
```

此外，`Login.vue` 在后端不可用时自动降级为 Mock 登录，用户察觉不到后端未启动，但进入系统日志页就会看到白屏。

### 只有真实用户操作才会产生 audit_log

来源包括：登录、设备 CRUD、策略变更、告警处理、用户/角色/权限管理。定时任务和 MQTT 自动行为不记审计日志。

## 2. 后端改动 — AuditLogController 增加筛选参数

`GET /api/logs/system` 新增可选查询参数：

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `page` | Integer | 否 | 页码，默认 1 |
| `size` | Integer | 否 | 每页条数，默认 10 |
| `operator` | String | 否 | 按操作人精确匹配 |
| `action` | String | 否 | 按操作类型匹配（如 LOGIN、DEVICE_CREATE、CONTROL） |
| `targetType` | String | 否 | 按目标类型匹配（DEVICE、POLICY、USER、ALARM、PERMISSION、SYSTEM） |
| `result` | String | 否 | 按结果筛选（SUCCESS / FAIL） |
| `dateFrom` | String | 否 | 开始时间（ISO datetime，含） |
| `dateTo` | String | 否 | 结束时间（ISO datetime，含） |

**改动位置**：`AuditLogController.java:21-32`

```java
@GetMapping("/system")
public Result<Page<AuditLog>> getSystemLogs(
        @RequestParam(defaultValue = "1") Integer page,
        @RequestParam(defaultValue = "10") Integer size,
        @RequestParam(required = false) String operator,
        @RequestParam(required = false) String action,
        @RequestParam(required = false) String targetType,
        @RequestParam(required = false) String result,
        @RequestParam(required = false) @DateTimeFormat(iso = DateTimeFormat.ISO.DATE_TIME) LocalDateTime dateFrom,
        @RequestParam(required = false) @DateTimeFormat(iso = DateTimeFormat.ISO.DATE_TIME) LocalDateTime dateTo) {

    LambdaQueryWrapper<AuditLog> wrapper = new LambdaQueryWrapper<>();
    wrapper.orderByDesc(AuditLog::getOperatedAt);
    
    if (StrUtil.isNotBlank(operator))
        wrapper.eq(AuditLog::getOperator, operator);
    if (StrUtil.isNotBlank(action))
        wrapper.eq(AuditLog::getAction, action);
    if (StrUtil.isNotBlank(targetType))
        wrapper.eq(AuditLog::getTargetType, targetType);
    if (StrUtil.isNotBlank(result))
        wrapper.eq(AuditLog::getResult, result);
    if (dateFrom != null)
        wrapper.ge(AuditLog::getOperatedAt, dateFrom);
    if (dateTo != null)
        wrapper.le(AuditLog::getOperatedAt, dateTo);
    
    Page<AuditLog> result = auditLogService.page(new Page<>(page, size), wrapper);
    return Result.success(result);
}
```
