# 项目上下文

## 项目背景

智慧路灯实验项目，基于重庆交通大学与中软国际人才培养集中实训方案，构建一套面向市政道路照明的物联网管理系统。通过传感器采集环境数据、MQTT 远程通信、后端自动策略控制，实现路灯的智能开关、调光、告警与数据分析。

## 项目结构

```
src/main/java/com/experiment/smartlightingexp/
├── config/          # 配置类（CORS、Knife4j、Jackson、MyBatis-Plus、JWT、自动填充）
├── entity/          # 实体类（Device、Telemetry、ControlCommand、AlarmRecord、LightingPolicy）
├── util/            # 工具类（JwtUtil）
└── SmartLightingExpApplication.java
```

## 核心功能模块

| 模块 | 说明 |
|------|------|
| 设备管理 | 路灯台账，记录设备身份、状态、位置 |
| 遥测数据 | 传感器上报光照、温湿度、PM2.5、PIR 等环境数据 |
| 设备控制 | MQTT 下发开/关/调光指令，支持手动和自动策略 |
| 告警管理 | 离线、高温、健康分过低等异常事件记录与通知 |
| 照明策略 | 基于阈值/时间/场景的自动节能规则引擎 |

## 数据库（MySQL 5 张核心表）

- **device** — 设备台账
- **telemetry** — 遥测数据
- **control_command** — 控制指令
- **alarm_record** — 告警记录
- **lighting_policy** — 照明策略
