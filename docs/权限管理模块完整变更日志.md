## 数据库变更

### 1. permission 表结构变更
```sql
ALTER TABLE `permission`
    ADD COLUMN `parent_id`    BIGINT      DEFAULT NULL COMMENT '父权限ID',
    ADD COLUMN `type`         VARCHAR(10) DEFAULT 'ACTION' COMMENT 'MODULE-模块, ACTION-操作',
    ADD INDEX idx_parent_id (parent_id);
```

### 2. menu 表（新增）
```sql
CREATE TABLE `menu` (
    id                BIGINT AUTO_INCREMENT,
    parent_id         BIGINT       DEFAULT NULL COMMENT '父菜单ID',
    name              VARCHAR(50)  NOT NULL COMMENT '菜单名称',
    permission_code   VARCHAR(50)  DEFAULT NULL COMMENT '关联权限编码',
    icon              VARCHAR(50)  DEFAULT NULL COMMENT '图标名称',
    path              VARCHAR(100) DEFAULT NULL COMMENT '前端路由路径',
    component         VARCHAR(100) DEFAULT NULL COMMENT '前端组件路径',
    sort              INT          DEFAULT 0 COMMENT '排序号',
    enabled           TINYINT(1)   DEFAULT 1 COMMENT '是否启用',
    create_time       DATETIME(3)  DEFAULT CURRENT_TIMESTAMP(3),
    PRIMARY KEY (id)
) COMMENT='动态菜单表';
```

## 后端功能说明

### `@RequirePermission` 注解

```java
@Target(ElementType.METHOD)
@Retention(RetentionPolicy.RUNTIME)
public @interface RequirePermission {
    String value();  // 如 "device:create"
}
```

### JWT 拦截器权限校验流程

```
1. Token 校验（过期/无效 → 401）
2. 提取 token 中的 permissions 列表
3. 检查方法上是否有 @RequirePermission
4. 有注解 → permissions.contains(required) → 放行或 403
5. 无注解 → 直接放行
```

### 菜单可见性逻辑（MenuServiceImpl）

```
getVisibleMenuTree(permissions):
  遍历菜单树
  - permission_code == NULL         → 保留（容器节点）
  - permissions 包含 permission_code → 保留
  - 否则                            → 移除
```

### 权限树逻辑（PermissionController）

```
GET /api/permissions/tree?roleId=1
→ 递归构建树
→ roleId 非空 → 查该角色已有权限 → 标记 checked
→ 返回树形结构供前端渲染权限分配界面
```

## 前端接入说明

### 不再硬编码导航栏
```javascript
// 登录成功后，直接使用返回的 menus 渲染导航
const res = await axios.post('/api/auth/login', { username, password })
// res.data.menus → 树形结构，包含 children 递归

// 页面刷新时请求 /me 重新获取
const me = await axios.get('/api/auth/me')
// me.data.permissions → ["device:read", "alarm:handle", ...]
// me.data.menus → 可见菜单树
```

### 新增功能菜单流程（无需改代码）
1. 超级管理员登录 → 菜单管理 → 新增菜单
2. 权限管理 → 新增模块权限 + 操作权限
3. 角色管理 → 分配新权限
4. 刷新 → 导航栏自动出现新菜单
