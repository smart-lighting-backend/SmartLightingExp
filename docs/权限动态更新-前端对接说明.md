# 权限动态更新 — 前端对接说明

> 日期：2026-07-03 | 涉及修改：JwtInterceptor / AuthController

---

## 一、改动背景

**之前：** 超级管理员为某个角色分配新权限后，该角色的用户必须**重新登录**才能生效（因为权限写死在 JWT Token 中，有效期 24 小时）。

**现在：** 分配权限后**立即生效**，不需要重新登录。用户下次请求或刷新页面即可看到更新。

---

## 二、前端需要配合的改动

### 1. 分配权限成功后，通知对应用户刷新

超级管理员在权限管理页面保存权限分配后：

```javascript
async function savePermissions(roleId, permissionIds) {
  const res = await axios.put(`/api/roles/${roleId}/permissions`, {
    permissionIds: permissionIds
  })
  // 保存成功
  message.success('权限分配成功，已生效')

  // 如果我正在修改自己的角色权限，需要刷新自己的菜单和权限
  const meRes = await axios.get('/api/auth/me')
  localStorage.setItem('userPermissions', JSON.stringify(meRes.data.permissions))
  localStorage.setItem('userMenus', JSON.stringify(meRes.data.menus))
  // 重新渲染导航栏
  renderSidebar(meRes.data.menus)
}
```

### 2. 其他角色用户如何感知权限变更

**方式一：页面刷新时自动拉取最新权限（推荐前端做）**

```javascript
// 在页面路由切换或定时器中，调用 /api/auth/me 刷新权限和菜单
async function refreshPermissions() {
  const meRes = await axios.get('/api/auth/me')
  
  const oldPermissions = JSON.parse(localStorage.getItem('userPermissions') || '[]')
  const newPermissions = meRes.data.permissions

  // 如果权限有变化，重新渲染导航和按钮
  if (JSON.stringify(oldPermissions) !== JSON.stringify(newPermissions)) {
    localStorage.setItem('userPermissions', JSON.stringify(newPermissions))
    localStorage.setItem('userMenus', JSON.stringify(meRes.data.menus))
    renderSidebar(meRes.data.menus)
    message.info('权限已更新')
  }
}

// 方案A：每次页面切换（路由变化）时检查
router.afterEach(() => refreshPermissions())

// 方案B：每 5 分钟轮询一次（不推荐，按需使用）
// setInterval(refreshPermissions, 5 * 60 * 1000)
```

**方式二：用户手动刷新浏览器（最简单，无需改代码）**

按 `F5` 或浏览器刷新按钮 → 前端重新加载 → 调用 `/api/auth/me` → 获取最新权限和菜单。

## 三、接口行为变化

### `/api/auth/me` 的权限返回值

```javascript
// 权限分配前 — 路灯管理员调用 /me
GET /api/auth/me
→ {
    "permissions": ["device:read", "device:create", "device:update", "device:delete",
                    "alarm:read", "alarm:handle", "policy:read", ...],
    "menus": [ ... ]
  }

// 超级管理员给路灯管理员增加了 "策略新增" 权限后
// 路灯管理员再次调用 /me（不需要重新登录）
GET /api/auth/me
→ {
    "permissions": ["device:read", "device:create", "device:update", "device:delete",
                    "alarm:read", "alarm:handle", "policy:read", "policy:create", ...],
    //                  ↑ 新权限已出现
    "menus": [ ... ]  // 如果新增了菜单，也会出现
  }
```

## 五、常见问题

| 问题 | 原因 | 解决 |
|:----|:-----|:-----|
| 分配权限后，对方看不到新权限 | 对方未刷新页面 | 手动刷新或调 `/me` |
| 分配权限后，对方仍然 403 | 拦截器缓存了旧权限 | 确认拦截器已更新为查数据库 |
| 导航菜单没有更新 | 菜单数据未刷新 | 调 `/me` 重新获取 `menus` |
| 按钮没有显示 | 按钮级权限未检查最新数据 | 刷新页面 |
