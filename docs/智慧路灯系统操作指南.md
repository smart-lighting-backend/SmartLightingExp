# 智慧路灯系统操作指南

本文档用于导入 MaxKB 知识库，作为系统操作和策略配置的知识来源。

## 如何查看设备状态

1. 登录系统后，默认进入仪表盘页面，顶部显示设备总数、在线数、在线率、节能率。
2. 左侧导航栏点击「设备管理」进入设备列表，可按区域、状态筛选。
3. 设备状态说明：1-在线（绿色）、2-离线（灰色）、3-异常（橙色）、0-停用（灰色）。
4. 点击设备名称进入详情页，可查看最新遥测、历史趋势、控制记录。

## 如何手动控制设备

1. 在设备详情页，点击「开灯」「关灯」或拖动亮度滑块进行调光。
2. 手动控制后 30 分钟内，AI 自动策略会跳过该设备，防止人机对抗。
3. 也可以在顶部导航栏点击「手动控制」按钮，在弹出的弹窗中选择设备和操作。

## 如何配置照明策略

1. 左侧导航栏点击「策略配置」，进入策略列表页。
2. 点击「新建策略」创建新策略。
3. 策略类型支持三种：
   - **THRESHOLD（阈值型）**：当光照强度低于/高于某值时触发，例如 `{"lux_lt": 50}` 表示光照低于 50 lux 时开灯。
   - **TIME（时段型）**：在指定时间段触发，例如 `{"time_range": "23:00-05:59"}` 表示深夜时段调光。
   - **SCENE（场景型）**：组合多条件触发（预留扩展）。
4. 动作支持：ON（开灯）、OFF（关灯）、DIMMING(亮度值)（调光到指定亮度，0-100）。
5. 优先级数字越小越优先：1 最高，10 最低。
6. 策略启用后才能被 AI 策略引擎执行。

## 如何优化节能策略

1. 夜间车流量低时段（23:00-05:59）设置 DIMMING(30) 调低至 30% 亮度，可节省约 70% 能耗。
2. 结合 PIR 人感数据：当检测到有人时提高亮度，无人时保持低亮度。
3. 光照联动：白天光照充足时自动关灯（lux_gt 阈值），傍晚光照不足时自动开灯（lux_lt 阈值）。
4. 多条策略配合使用：高优先级策略处理紧急场景（如高峰照明），低优先级策略处理常规节能。
5. 建议配置组合示例：
   - 策略1（优先级1）：光照 < 50 lux → 开灯 100%（确保基本照明）
   - 策略2（优先级5）：深夜 23:00-05:59 → 调光至 30%（节能）
   - 策略3（优先级8）：PIR 检测有人 → 调光至 70%（按需增亮）

## 节能率是如何计算的

1. 节能率 = (1 - 平均亮度 / 100) × 100%。
2. 平均亮度是全天的时间加权平均值。
3. 例如：12 小时以 60% 亮度运行，其余 12 小时关灯，平均亮度为 30%，节能率为 70%。
4. 系统每日自动统计各设备的节能率，并在仪表盘展示汇总数据。

## 如何查看告警信息

1. 左侧导航栏点击「告警中心」，可查看所有告警记录。
2. 告警类型：OFFLINE（离线）、OVER_TEMP（高温）、HEALTH_LOW（健康分低）、VISION_ABNORMAL（视觉异常）。
3. 告警级别：CRITICAL（严重）、MAJOR（主要）、MINOR（次要）。
4. 设备恢复在线后，离线告警会自动标记为 RECOVERED。
5. 告警详情页可查看告警触发时间、恢复时间、处理建议。

## 如何处理设备离线告警

1. 查看设备最后心跳时间和遥测上报时间。
2. 如果是同区域批量离线，优先排查网络或网关。
3. 如果是单灯离线，检查设备通信模块、天线和本地供电。
4. 设备重新上报遥测数据后，系统会自动恢复离线告警。
5. 如果设备长期离线且无法恢复，考虑安排现场巡检。

## 如何查看能耗数据

1. 左侧导航栏点击「数据报表」，进入能耗统计页面。
2. 查看年度总能耗、年度节省量、碳减排量等汇总指标。
3. 月度能耗对比柱状图：对比实际能耗与节省量。
4. 分区能耗占比饼图：查看各区域的能耗分布。
5. 仪表盘页面右侧可查看分区设备状态和能耗趋势。

## 如何看懂健康评分

1. 设备健康评分范围 0-100，越高越好。
2. 评分 ≥ 80：设备状态良好。
3. 评分 60-79：需要关注，建议检查遥测数据是否异常。
4. 评分 < 60：设备需要维修，系统会生成告警通知。
5. 评分受以下因素影响：心跳离线次数、指令失败率、传感器异常、告警频次。

## 如何使用 AI 智能助手

1. 左侧导航栏点击「智能助手」，进入 AI 问答界面。
2. 可以直接输入问题，如：「灯不亮怎么办」「如何优化节能策略」。
3. 也支持调整阈值：输入「把阈值调到30」，系统会自动修改策略配置。
4. AI 助手的回答基于知识库文档，请确保知识库内容完整准确。

## 系统有哪些仪表盘指标

1. 设备总数：系统接入的路灯总数。
2. 在线率：在线设备占总数的百分比。
3. 节能率：当日节能率的汇总数据。
4. 未处理告警：当前 ACTIVE 状态的告警数量。
5. 能耗走势：当日 vs 上周同期的逐小时能耗对比。
6. 分区设备状态：按区域统计设备的在线/离线/告警数量。
